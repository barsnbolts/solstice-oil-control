# Solstice GXP oil-control project site

Static HTML/CSS/JS, hosted by GitHub Pages. The public site compares current A/B/C concepts, their animations and interactive pan-context views, prototype STEP/DXF/GLB downloads, editable CAD source, fabrication/measurement notes and sixteen manufacturer reference links. Historical fixed-divider and purchased-door concepts remain available below the current comparison.

The `dist/` directory is the published edition. Pushes to `main` automatically deploy it with GitHub Actions. The open page checks for a new edition every minute and when returning to the tab, then offers a **Load update** button. A refresh never interrupts reading or video automatically.

To update from the local CAD project, first build a preview with `python3 site/build.py --preview`, have that exact edition independently reviewed, and complete the project package. Then run `python3 site/publish.py` from the parent workspace. The publisher verifies the current candidate, package receipt, accepted candidate hash, accepted site edition and portable bundle, then commits that exact `dist/` without regenerating timestamps or changing the reviewed edition. It fails closed if any identity differs. Complete the project checks/review/package first when CAD or project evidence changes. GitHub does not read the local workspace by itself; the update command publishes the accepted edition.

`build.py` and `publish.py` are workspace-side helpers. They require the full local project as the parent directory; a standalone GitHub clone can edit the public `dist/` files and push them directly. `check_dist.py` is intentionally independent of that private workspace and runs in GitHub Actions before every deployment.

The public ZIP preserves STEP/DXF/BOM directory relationships and contains editable source and animation sidecars. It is a curated export, not the complete local evidence/validation workspace. Local paths, private review logs and downloaded source archives are not published. One official GM pan photograph is displayed with attribution beside the explicitly assumed reconstruction. Other manufacturer references remain links. Google model-viewer 4.4.0 is vendored with its license to provide touch/keyboard orbit and gate playback.

All models are nominal prototypes. Pan/pickup/mount geometry and physical performance remain unverified. No order, fabrication release or engine-use acceptance is implied.

P4 quality checks run in the main project: one shared dimensional source, generated register and summary, BOM regressions, full flat STEP/DXF equivalence, sampled independent gate/proxy clearance and exact media receipts. The public `catalog.json` drives the A/B/C selector and binds every detail/exploded/section asset to that candidate. Unchanged geometry validation and media are reused by content hash. Use `python3 site/build.py --preview` only for an unpublished local preview of a frozen candidate; publishing always requires accepted and packaged candidate identity.
